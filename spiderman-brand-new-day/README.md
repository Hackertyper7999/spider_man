# Spider-Man: Brand New Day — Fan Site

Unofficial fan website for **Spider-Man: Brand New Day** (releases **July 31**).

## Features

- Full-bleed hero with Brand New Day branding
- Countdown to July 31, 2026
- Movie sections: Spider-Man 1–3, Amazing Spider-Man 1–2, MCU films
- 25+ image gallery with hover effects
- 20+ CSS/JS animations and effects
- “Who's Excited” fan form (name, place, age, number, email, Instagram)
- Admin panel to view/delete all inquiries

## Run

```bash
npm install
npm start
```

- Site: http://localhost:3000  
- Admin: http://localhost:3000/admin  

Inquiries are stored in `data/inquiries.json`.

This is a fan-made tribute and is not affiliated with Marvel Studios or Sony Pictures.
